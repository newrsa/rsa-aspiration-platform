# Neo4j Notebooks

This directory contains single-file manual runbooks for Neo4j Browser.

## Manual Seed Smoke Test

`manual_seed_smoke_test.cypher` is generated by:

```powershell
python scripts\generate_neo4j_notebook.py
```

Before running it:

1. Start Neo4j.
2. Copy `datasets/seed` into Neo4j's import directory as `seed`.
3. Open `manual_seed_smoke_test.cypher`.
4. Run each numbered section in order.

The notebook applies constraints and indexes, loads the seed dataset, verifies the core Science pathway, and runs structural validation queries.

## Query Capability Cookbook

`query_capability_cookbook.cypher` is generated by:

```powershell
python scripts\generate_query_cookbook.py
```

Run it after `manual_seed_smoke_test.cypher`.

It contains representative query patterns for pathway, eligibility, entrance exam, career, licence, institution, geography, financial aid, competency, and structural validation capabilities.
