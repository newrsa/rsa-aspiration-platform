# Datasets

This directory holds versioned data fixtures and import-ready CSVs.

## Seed Dataset

`seed/` is generated by `python scripts/generate_seed_csv.py`.

It contains:

- one small connected Science pathway sample
- header-only CSV files for the remaining ontology entities and relationships
- files matching the generated Neo4j loader expectations

The seed dataset exists for smoke testing the schema and loader pipeline. It is not production data.
